# 📦 Projeto de Relatórios com Java Stream API (CLI)

Este é um projeto educacional em Java voltado para a prática da **Stream API**, utilizando um menu em linha de comando (CLI) com **dados mocados**. O objetivo é aplicar `map`, `filter`, `sorted`, `limit`, `reduce` e outras operações simples de forma clara e funcional.

## 📌 Funcionalidades atuais

Atualmente, o sistema trabalha com um **catálogo de produtos** e permite executar os seguintes relatórios:

### 🛍️ Relatórios de Produtos
- Listar produtos ordenados por nome
- Filtrar produtos com estoque abaixo de 10
- Listar apenas os nomes dos produtos
- Listar nomes dos produtos da categoria `"Papelaria"`
- Calcular o valor total do estoque (preço × quantidade)
- Listar os 3 produtos mais caros

Todos os relatórios devem ser implementados usando **Stream API** de forma funcional e enxuta.

## 🚀 Como rodar

1. Clone este repositório ou copie os arquivos fonte:
   ```bash
   git clone https://github.com/seu-usuario/nome-do-projeto.git
   ```
2. Compile o projeto com sua IDE Java favorita (IntelliJ, VS Code, Eclipse) ou via terminal com:
   ```bash
   javac Main.java
   java Main
   ```
3. Navegue pelo menu digitando o número da opção desejada.

> 💡 Este projeto usa apenas Java puro e pode ser executado em qualquer ambiente que tenha o JDK 17 ou superior.
